# Flask DevOps Demo

A beginner-friendly DevOps project demonstrating a Python Flask web application, Docker containerization, automated testing, CI with GitHub Actions, and cloud deployment using Render.

## Features
- Flask web application
- Health-check endpoint (`/health`)
- Docker containerization
- Automated tests using pytest
- Continuous Integration using GitHub Actions
- Cloud deployment using Render

## Tech Stack
Python, Flask, pytest, Docker, GitHub Actions, Render

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000` in your browser.

## Health Check
`/health` returns the application's health status.
